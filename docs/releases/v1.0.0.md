# v1.0.0 — BCMP Conjecture 4.30 in Lean

A review snapshot for readers of Bruin, Carminati, Marmi and Profeti. The [final theorem](../../formal/Final430.lean) covers every integer $s\ge2$, includes the untuned parameter $0$, and excludes only the top endpoint $s/(s+1)$ from the untuned set. Start with the [paper-to-Lean guide](../paper-to-lean.md) and [reproduction instructions](../../README.md#reproduce-the-check).
